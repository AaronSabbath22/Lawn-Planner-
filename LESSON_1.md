# Study hour, Wed Nov 4: Session 1 of the lawn treatment planner
New idea tonight: an API. A website that answers a program instead of a person.
1. (10 min) Open the forecast URL from spray_day.py in Safari. That raw JSON is what the program reads.
2. (15 min) Read spray_day.py top to bottom. The rules near the top are your spray rules as code.
3. (15 min) Run it (copy the whole file into Python Code Pad, tap Run). Compare with what you know from the field.
4. (15 min) Change one rule to match how you actually spray (for example wind max or temp max) and rerun.
5. (5 min) Write down one rule you use that the script is missing. That is Session 2.
